# Tez Kömek — іске қосу нұсқаулығы

Сайт: бағалар тізімі (WhatsApp арқылы тапсырыс), тіркелу/кіру, «Сіз кімсіз?» сұрағы, жеке кабинет, Kaspi арқылы қолмен төлем, админ панель.
Технология: GitHub Pages (сайттың өзі, тегін) + Supabase (аккаунттар мен база, тегін).

Файлдар:
- `index.html`, `styles.css`, `app.js` — сайттың өзі (өзгертудің қажеті жоқ)
- `config.js` — **тек осыны өзгертесіз** (Supabase кілттері, Kaspi нөмірі, WhatsApp)
- `supabase.sql` — базаны құратын скрипт

---

## 1-қадам. Supabase жобасын ашу (5 минут)

1. https://supabase.com сайтына кіріп, **Start your project** → GitHub аккаунтыңызбен кіріңіз.
2. **New project** басыңыз. Атын жазыңыз (мысалы `tez-komek`), құпиясөз ойлап табыңыз, аймақ ретінде **Frankfurt (eu-central-1)** таңдаңыз → **Create**.
3. Жоба дайын болғанда сол жақтағы **SQL Editor** → **New query** ашыңыз.
4. `supabase.sql` файлының ішіндегі бәрін көшіріп қойып, **Run** басыңыз. «Success» шықса болды.
5. **Project Settings → API** бөліміне өтіп, екі нәрсені көшіріңіз:
   - **Project URL** (мысалы `https://abcd1234.supabase.co`)
   - **anon public** кілті (ұзын мәтін)
6. **Authentication → URL Configuration** бөлімінде **Site URL** жолына сайтыңыздың мекенжайын жазыңыз (3-қадамнан кейін белгілі болады, мысалы `https://username.github.io/tez-komek/`).

> Кеңес: оқушылар растау хатын таппай қалмас үшін **Authentication → Sign In / Providers → Email** ішінде «Confirm email» опциясын өшіріп қоюға болады. Сонда тіркелген бойда кіре береді.

## 2-қадам. config.js файлын толтыру

`config.js` файлын ашып, мына жолдарды толтырыңыз:

```js
SUPABASE_URL: "https://abcd1234.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
KASPI_PHONE: "+7 7xx xxx xx xx",
KASPI_NAME: "Аян Е.",
WHATSAPP: "77xxxxxxxxx",
```

`anon` кілтін ашық сайтқа қоюға болады — қауіпсіздікті базадағы ережелер (RLS) қамтамасыз етеді: ешкім төлемеген жұмысты аша алмайды.

## 3-қадам. GitHub-қа жүктеу

1. https://github.com/new → репозиторий атын жазыңыз (мысалы `tez-komek`), **Public** → **Create repository**.
2. «uploading an existing file» сілтемесін басып, барлық файлдарды (`index.html`, `styles.css`, `app.js`, `config.js`) сүйреп салыңыз → **Commit changes**.
3. Репозиторийде **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка: **/ (root)** → **Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады: `https://СІЗДІҢ-ЛОГИН.github.io/tez-komek/`

## 4-қадам. Өзіңізді админ ету

1. Сайтқа өз email-іңізбен тіркеліңіз.
2. Supabase → **SQL Editor** → мына жолды іске қосыңыз (email-ді ауыстырып):
   ```sql
   update public.profiles set is_admin = true where email = 'сіздің@email.kz';
   ```
3. Сайтты жаңартыңыз — жоғарыда **Админ** батырмасы пайда болады.

## Бағаларды өзгерту

`config.js` ішіндегі `PRICES` бөлімінде әр қызметтің атауы, көлемі мен бағасы тұр. Санды өзгертіп, файлды GitHub-қа қайта жүктесеңіз болды. `price: null` деп жазсаңыз — «Келісім бойынша» деп шығады. Жаңа жол немесе жаңа бөлім қосуға болады.

## Тапсырыстар

- Тапсырысты тек тіркелген адам бере алады. «Тапсырыс беру» басқанда тапсырыс базаға нөмірмен (№1, №2…) жазылады, сосын WhatsApp сізге дайын хабарламамен ашылады: нөмірі, не керек, сомасы, клиенттің аты мен email-і.
- Промокод (TEZ20) тек адамның **алғашқы** тапсырысына жарайды — мұны база өзі тексереді.
- Админ → **Тапсырыстар** бөлімінде барлық тапсырыстар тұр; күйін өзгертесіз: Жаңа → Жұмыста → Дайын (немесе Бас тартылды). Клиент күйін өз кабинетінен көреді.
- Ескерту: сома клиенттің браузерінде есептеледі — WhatsApp-та сомасын бір қарап шығыңыз.

## Күнделікті жұмыс

1. **Клиент WhatsApp-қа жазады** (сайттағы «Тапсырыс беру» батырмасы хабарламаны дайын мәтінмен ашады).
2. Бағасын келісесіз, клиент **Kaspi-ге төлейді** және **сайтқа тіркеледі**.
3. Жұмыс дайын болғанда: Админ → **Тапсырыс жұмыстары** → «+ Жаңа жұмыс». Атауын жазып, жұмыстың өзін қосасыз: файл (PDF/PPTX/DOCX) немесе сілтеме (Canva, Google Drive). Бұл жұмыстар каталогта ешкімге көрінбейді.
4. Админ → **Қолданушылар** → клиенттің қасынан жұмысты таңдап → **«Доступ беру»**. Жұмыс клиенттің кабинетінде бірден ашылады.

**Қауіпсіздік:** жүктелген файлдар жабық қоймада сақталады; доступ берілген адамға ғана 1 сағаттық уақытша сілтеме беріледі. Сілтеме түрінде қосылған жұмысты (мысалы Canva) клиент басқаға жібере алатынын ескеріңіз — құнды жұмыстарды PDF ретінде жүктеген дұрыс.

## Демо режим

`config.js` ішінде Supabase кілттері бос тұрса, сайт демо режимде ашылады: кез келген email-мен кіруге болады (email «admin» деп басталса — админ панель ашылады). Ешнәрсе сақталмайды.
